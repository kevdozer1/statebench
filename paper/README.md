# statebench paper

An arXiv-style write-up of statebench: what a text description of a robot scene must contain for a language model to
act on it.

## Files

- `statebench_paper.tex`: the LaTeX source, a single-column arXiv-style preprint.
- `statebench_paper.pdf`: the compiled paper. It is also hosted at
  <https://kevdozer1.com/assets/pdf/statebench_paper.pdf>.
- `statebench_paper.md`: a Markdown version of the same content, generated by `tex2md.py`.
- `blog_abstract_block.md`: the abstract, with links to the PDF and the code.
- `figures/`: every figure the paper uses. `make_diagrams.py` draws the System 1/System 2 diagram, and
  `structured_state.svg` is the source of the structured-state figure.

## Build

With MiKTeX or TeX Live:

```
cd paper
pdflatex statebench_paper.tex
pdflatex statebench_paper.tex
python tex2md.py
```

The bibliography is written inline with `thebibliography`, so no BibTeX pass is needed. Two `pdflatex` passes resolve
the cross-references.

## Where the numbers come from

Every number in the paper comes from the pre-registered runs of the 19 rounds described in
[docs/HISTORY.md](../docs/HISTORY.md), and the headline results are also in [results/RESULTS.md](../results/RESULTS.md).
The code that produced them is in `src/statebench/` and `scenes/`.
